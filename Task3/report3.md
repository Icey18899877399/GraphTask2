# 实验三：LZW 编解码实验

## 一、实验目标

对灰度图像 `b8gray.bmp` 进行 LZW 编码，输出压缩文件 `C.dat`；再以 `C.dat` 为输入进行 LZW 解码，输出解码图像 `Id.bmp`。计算编码后的 bpp 值、原灰度图像的熵，并验证原图 `Is` 与解码图 `Id` 是否完全相同。

## 二、编码框图

```mermaid
flowchart TD
    A["读入原灰度图像 Is: b8gray.bmp"] --> B["提取像素序列"]
    B --> C["初始化 LZW 字典: 0-255"]
    C --> D["逐像素查找最长已知序列"]
    D --> E{"当前序列+新像素 在字典中?"}
    E -- 是 --> F["扩展当前序列"]
    E -- 否 --> G["输出当前序列编码"]
    G --> H["把 当前序列+新像素 加入字典"]
    H --> I["从新像素开始下一序列"]
    F --> D
    I --> D
    D --> J["输出末尾序列编码"]
    J --> K["写入 C.dat: 图像信息、调色板、LZW码流"]
```

## 三、编码代码

编码代码位于 `Task3/main.cpp`，核心函数为：

- `LzwEncode(...)`：完成 LZW 字典编码。
- `SaveCompressedFile(...)`：保存 `C.dat`，其中包含图像尺寸、调色板和 16 bit LZW 码流。
- `CalculateEntropy(...)`：计算原图灰度熵。

## 四、解码框图

```mermaid
flowchart TD
    A["读入压缩文件 C.dat"] --> B["读取图像信息、调色板、LZW码流"]
    B --> C["初始化 LZW 字典: 0-255"]
    C --> D["读取第一个编码并输出对应像素序列"]
    D --> E["逐个读取后续编码"]
    E --> F{"编码已在字典中?"}
    F -- 是 --> G["输出该编码对应序列"]
    F -- 否 --> H["处理 KwKwK 特殊情况"]
    G --> I["把 上一序列+当前序列首像素 加入字典"]
    H --> I
    I --> J{"码流结束?"}
    J -- 否 --> E
    J -- 是 --> K["重建并保存 Id.bmp"]
    K --> L["逐像素比较 Is 与 Id"]
```

## 五、解码代码

解码代码位于 `Task3/main.cpp`，核心函数为：

- `LoadCompressedFile(...)`：读取 `C.dat`。
- `LzwDecode(...)`：按 LZW 规则恢复像素序列。
- `PutImageBytes(...)`：根据解码像素和调色板生成 `Id.bmp`。
- `SameImage(...)`：验证原图与解码图是否完全一致。
